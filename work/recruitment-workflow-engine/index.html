A workflow engine for recruitment and onboarding

Reusable workflow templates, a full task state machine, and tokenised links that let outside vendors complete tasks with no login.

C# / .NETState machinesIntegrationsAI scoring

Problem

Recruitment and onboarding work crosses people and systems: hiring managers, HR, and external vendors, with integrations to Sage 300, LinkedIn and Careers24. It needed to be modelled as real workflows with rules, not a checklist.

Process

Built end to end as part of a three-person team at Genghis Technology, including the workflow system and the employee onboarding flow.

Architecture

  • Templates are separate from runtime instances. A reusable workflow template describes the shape of the work; a live instance is what actually runs for one person.
  • Tasks carry assignment, ordering and due-date rules.

Implementation

  • A full task state machine: completion, decline, skip, expiry and reassignment.
  • Token-based external completion. Vendors complete assigned tasks through secure, tokenised links, with no login and no account.
  • Audit trails that record reassignment and ordering changes.
  • The employee onboarding flow, end to end, and a Sage VIP data export.
  • A two-stage AI CV-scoring evaluation: evidence is extracted first, then mapped against a rubric. Separating the stages keeps the scoring explainable.

Reliability

Every task transition is an explicit state rather than an ad-hoc flag, external access is limited to a single task through a tokenised link, and changes to ownership and ordering are recorded.

Result

A workflow system delivered and run in production for a client environment, covering the lifecycle from recruitment through to onboarding and payroll-system export.

Employer systems, repositories, work items and client names are deliberately left out. The mechanism is the point.
